Publier vos modifications

  1. Modifiez les rubriques, puis cliquez sur Aperçu du site pour vérifier le rendu.
  2. Cliquez sur Enregistrer content.js. Avec Chrome ou Edge, choisissez le fichier assets/js/content.js du portfolio pour le remplacer directement ; sinon le fichier est téléchargé et vous le copiez à cet endroit.
  3. Pour un site en ligne sur GitHub : envoyez le nouveau assets/js/content.js (et vos nouvelles images) dans le dépôt.
  4. Images, captures et CV : copiez les fichiers dans assets/img/ ou assets/cv/, puis indiquez leur chemin dans le champ correspondant.
